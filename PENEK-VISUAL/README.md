# PENEK VISUAL

Самостоятельный клиентский визуальный мод для Minecraft 1.21.11 на Fabric.
Собственный интерфейс в стилистике современных ClickGUI-клиентов.

## Возможности первой версии
- Меню по Right Shift.
- Разделы HUD, VISUALS, INTERFACE, SETTINGS.
- Переключатели HUD, Watermark, FPS и координат.
- HUD с названием клиента, FPS и координатами.
- Тёмная панель с фиолетовым акцентом.

## Сборка
Нужны JDK 21 и Gradle. Из этой папки выполни:
```bash
gradle build
```
JAR появится в `build/libs/`.

Исходники первой версии. JAR ещё не собран и совместимость API требует проверки.
